# DQN в простой клеточной среде

Цель курсовой - обучить агента доезжать до заданного узла сетки и измерить, насколько его маршруты близки к кратчайшим по числу действий.

## Среда

Рабочий вариант - поле из 10 × 10 клеток. Агент движется по рёбрам между вершинами клеток, поэтому допустимых позиций 11 × 11. Координаты узлов `x` и `y` принимают целые значения от 0 до 10. Ось `x` направлена вправо, ось `y` - вниз. На поле нет внутренних препятствий.

В начале эпизода задаются стартовый узел, начальное направление и целевой узел. Старт и цель различаются. При обучении эти параметры выбираются случайно из обучающих сценариев. При демонстрации цель задаёт пользователь.

Агент ориентирован в одну из четырёх сторон. За один шаг он выполняет ровно одно действие.

| Действие | Что происходит |
| --- | --- |
| Вперёд | Агент переезжает в соседний узел по текущему направлению. Если впереди граница поля, агент остаётся на месте. |
| Поворот влево | Агент поворачивается на 90° против часовой стрелки и остаётся в том же узле. |
| Поворот вправо | Агент поворачивается на 90° по часовой стрелке и остаётся в том же узле. |

Например, если агент стоит в `(2, 3)` лицом вправо, а цель - `(2, 2)`, кратчайший маршрут состоит из двух действий: поворот влево и шаг вперёд.

## Наблюдение и награда

Наблюдение содержит координаты агента `(x, y)`, координаты цели `(goal_x, goal_y)` и направление агента. Координаты делятся на 10. Направление кодируется четырьмя числами, из которых ровно одно равно 1. Всего на вход сети поступает 8 чисел.

Предлагаемая награда - `-1` за каждое действие, включая шаг, которым агент достигает цели. Попытка выехать за границу стоит `-2`. Штраф за шаг поощряет короткие маршруты с учётом поворотов.

Эпизод завершается при достижении целевого узла с любым направлением. Лимит в 100 действий прерывает эпизод, если агент ещё не доехал. Достижение цели на последнем шаге считается успехом.

## Обучение DQN

Небольшая полносвязная сеть на PyTorch возвращает три Q-оценки, по одной на действие. Для обучения используются буфер переходов, целевая сеть и ε-жадный выбор действий. В начале обучения агент чаще исследует среду случайными действиями. При оценке он всегда выбирает действие с максимальной Q-оценкой.

## Эксперимент

Пары «старт - цель» заранее делятся на обучающие, валидационные и тестовые. Одна и та же пара со всеми начальными направлениями попадает только в одну выборку. На валидации подбираются параметры обучения. На тесте измеряется качество на новых сочетаниях старта и цели.

Для сравнения используются случайный агент и поиск в ширину (BFS). BFS ищет маршрут по состояниям `(x, y, направление)`, поэтому учитывает повороты и даёт минимальное число действий до цели. Все методы оцениваются на одних и тех же тестовых сценариях.

- Доля эпизодов, в которых агент достиг цели за 100 действий.
- Среднее превышение числа действий над BFS среди успешных эпизодов. Этот показатель оценивается вместе с долей успехов.
- Динамика доли успешных эпизодов на валидации по мере обучения.

## Демонстрация

На сетке показываются выбранная цель, начальная позиция, траектория агента и его направление. После эпизода показываются результат, число действий агента и минимальное число действий по BFS.
